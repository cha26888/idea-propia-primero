| Tecnología | ¿Para qué la utilizamos? | ¿Por qué la elegimos? |
|---|---|---|
| **Java 25** | Desarrollo de la lógica principal del sistema. | Es robusto, orientado a objetos y facilita mantener el código organizado. |
| **Spring Boot 4.1.1** | Construcción del backend de la aplicación. | Simplifica la configuración y agiliza el desarrollo de aplicaciones web. |
| **Spring MVC** | Gestión de solicitudes HTTP y controladores. | Permite separar responsabilidades y mantener una arquitectura ordenada. |
| **SQLite** | Almacenamiento de información. | Es ligero, portable y no necesita un servidor de base de datos independiente. |
| **Thymeleaf** | Generación de páginas HTML dinámicas. | Se integra directamente con Spring Boot, evitando un frontend completamente separado. |
| **Spring Security** | Autenticación y protección de rutas. | Proporciona mecanismos de seguridad integrados y configurables. |
| **HTML5** | Estructura de las páginas web. | Es el estándar para desarrollar interfaces web accesibles y compatibles. |
| **CSS3** | Diseño visual y adaptación a diferentes pantallas. | Permite personalizar la interfaz sin depender de frameworks visuales pesados. |
| **JavaScript** | Interactividad del chat y otras funcionalidades. | Permite actualizar elementos de la interfaz sin recargar constantemente las páginas. |
| **Marked.js** | Interpretación de Markdown en el chat. | Facilita mostrar respuestas estructuradas, listas y fragmentos de código. |
| **DOMPurify** | Sanitización del HTML generado. | Ayuda a reducir riesgos de seguridad al mostrar contenido dinámico. |
| **KaTeX** | Representación de expresiones matemáticas. | Permite mostrar fórmulas de forma clara, rápida y legible. |
| **Maven** | Gestión de dependencias, compilación y pruebas. | Automatiza tareas y facilita reproducir el entorno de desarrollo. |
| **JUnit / Spring Test** | Pruebas automatizadas. | Permiten comprobar el funcionamiento del sistema y detectar errores después de realizar cambios. |
| **Git y GitHub** | Control de versiones y colaboración. | Facilitan trabajar mediante ramas, integrar cambios y mantener un historial del proyecto. |
